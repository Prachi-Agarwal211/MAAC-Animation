## 📄 Page Template Structure

Each location page should include:

### 1. Meta Tags
```typescript
title: "Animation Course in [Location], Jaipur | MAAC Institute"
description: "Looking for animation courses in [Location]? MAAC offers B.Voc, diploma in 3D Animation, VFX, Game Design. 95% placement. Free demo class."
keywords: [
  "animation course [location] jaipur",
  "vfx training [location]",
  "3d animation institute near me",
  "best animation college in [location]",
  "maac jaipur [location]",
]
```

### 2. Structured Data
```json
{
  "@context": "https://schema.org",
  "@type": "EducationalOrganization",
  "name": "MAAC Jaipur - [Location] Center",
  "areaServed": {
    "@type": "Place",
    "name": "[Location], Jaipur"
  }
}
```

### 3. On-Page Content

#### H1 Heading
"Animation Courses in [Location], Jaipur"

#### Key Sections:
- **Why Choose MAAC in [Location]?** (5-6 bullet points)
- **Serving Nearby Areas** (mention 3-4 nearby localities)
- **Courses Offered** (3-4 course cards)
- **Contact/Visit Card** (address, phone, hours, CTA)
- **Map Embed** (Google Maps showing location)
- **Student Testimonials** (from that area if possible)
- **FAQs** (location-specific)

#### Internal Links:
- Link to main courses page
- Link to contact page
- Link to other location pages
