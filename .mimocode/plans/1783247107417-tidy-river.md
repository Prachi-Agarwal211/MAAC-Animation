# MAAC Website — Comprehensive Design Audit & Overhaul Plan

## Executive Summary

After auditing 30+ files against the design bible, I found **120+ specific issues** across 8 categories. The 5 most critical problems:

1. **Red is everywhere** — used in 15+ distinct roles (blobs, dividers, buttons, shader, ticker, progress bar, ink fills, placeholders, selection). When everything is red, nothing stands out.
2. **Shadows are ad-hoc** — a 5-tier elevation system exists in CSS but ZERO components use it. Every component hardcodes its own shadow.
3. **No spring physics** — GSAP uses `expo.out` / `power2.out` everywhere. Spring easings are defined but never used. Hover effects are generic CSS `duration-300 ease`.
4. **Inter is the body font** — the design bible explicitly says "NOT Inter, Roboto, or Poppins." This single font choice makes the site feel AI-generated.
5. **Inconsistent interaction timing** — hover transitions range from 150ms to 1000ms with no system.

## PHASE 4: Spring Physics & Motion System

### Problem
GSAP uses `expo.out` / `power2.out` everywhere. Spring easings (`elastic.out`, `back.out`) are defined but never used. Hover effects are generic CSS `transition-all duration-300`. The MagneticButton has spring on leave but power2 on approach (inconsistent).

### Changes

**`src/app/globals.css`:**
- Add spring timing tokens:
```css
:root {
  --ease-spring-bouncy: cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-spring-smooth: cubic-bezier(0.16, 1, 0.3, 1);
  --ease-spring-snappy: cubic-bezier(0.2, 0, 0, 1);
  --ease-spring-elastic: cubic-bezier(0.68, -0.55, 0.27, 1.55);
  --duration-fast: 200ms;
  --duration-normal: 400ms;
  --duration-slow: 700ms;
}
```

**GSAP animation upgrades (useGSAP hooks):**

| File | Line | Current Ease | New Ease |
|------|------|-------------|----------|
| `MAACXHero.tsx` | 59-69 | `expo.out` | `back.out(1.7)` |
| `CustomCursor.tsx` | 28-34 | `power3.out` | `elastic.out(1, 0.4)` |
| `MagneticButton.tsx` | 29 | `power2.out` | `elastic.out(1, 0.6)` |

**CSS hover upgrades (replace generic transitions):**
- `.glass-card`: `transition: transform 0.5s var(--ease-spring-bouncy), box-shadow 0.5s var(--ease-spring-smooth)`
- `.btn-primary`: `transition: transform 0.4s var(--ease-spring-bouncy), box-shadow 0.4s var(--ease-spring-smooth)`

**Add velocity-based scroll skew to key components:**
```javascript
// Add to HeroTrustTransition, VerticalCardGallery, StudentShowcase
ScrollTrigger.create({
  trigger: element,
  onUpdate: (self) => {
    const velocity = self.getVelocity();
    gsap.to(element, {
      skewX: velocity * 0.0008,
      duration: 0.3,
      ease: "power2.out"
    });
  }
});
```

## PHASE 7: Mobile Experience Polish

### Problem
No haptic feedback. Touch interactions are basic `active:scale-[0.95]`. Mobile bottom nav uses `backdrop-blur-3xl` (GPU-heavy). Thumbnail videos all load simultaneously.

### Changes

**Create `src/hooks/useHaptic.ts`:**
```typescript
export function useHaptic() {
  const vibrate = (pattern: number | number[]) => {
    if (typeof navigator !== 'undefined' && navigator.vibrate) {
      navigator.vibrate(pattern);
    }
  };
  return { tap: () => vibrate(50), success: () => vibrate([50, 30, 50]), error: () => vibrate([100, 30, 100]) };
}
```

**`src/components/FloatingActions.tsx`:**
- Line 143: Reduce `backdrop-blur-3xl` to `backdrop-blur-xl` (24px → less GPU)
- Lines 148, 155, 162: Increase `active:scale-[0.95]` to `active:scale-[0.92]` + add `transition-transform duration-150`

**`src/components/StudentShowcase.tsx`:**
- Lines 226-232: Replace thumbnail `<video>` elements with static `<Image>` poster images. Only load video on hover (desktop) or tap (mobile)
- Line 155-159: Fix loading spinner condition — only show when `isVideoLoading`, not when playing

**`src/app/globals.css`:**
